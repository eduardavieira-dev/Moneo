# MONEO

*(do latim "moneo", que significa "advertir" ou "aconselhar")*

![Projeto Moneo](projeto.png)

**MONEO** é uma plataforma digital com o objetivo de auxiliar os usuários a gerenciar suas finanças pessoais e promover a educação financeira. Através de uma interface intuitiva e fácil de usar, a aplicação oferece ferramentas para controle de gastos, simulação de investimentos de longo prazo e acesso a conteúdos educativos, como livros, cursos e notícias. O **MONEO** visa ajudar seus usuários a conquistarem autonomia financeira e a tomarem decisões mais informadas, conquistando a liberdade financeira e vivendo com maior tranquilidade.

## 🚀 Funcionalidades

- **Controle de Gastos**: Uma planilha simples e eficiente para registrar e organizar todas as despesas.
- **Simulação de Investimentos**: Calculadora para ajudar a planejar investimentos e ver seus resultados ao longo do tempo.
- **Educação Financeira**: Seção com sugestões de livros, cursos e notícias que incentivam a educação financeira contínua.

## 🛠️ Tecnologias Utilizadas

- **HTML**: Estruturação do conteúdo da página.
- **CSS**: Estilização visual para garantir uma experiência de usuário fluida e agradável.
- **JavaScript**: Para interatividade e funcionalidades dinâmicas na interface.
- **JSON e JSON-server**: Utilizado como banco de dados temporário para armazenar e manipular dados.
- **Node.js**: Ambiente de execução JavaScript no back-end, permitindo a criação de APIs e processamento de dados do servidor.

## 🎯 Sobre o Projeto

Este projeto foi desenvolvido durante o primeiro semestre do curso de Engenharia de Software, como parte da disciplina **Trabalho Interdisciplinar 1**. O objetivo é criar uma plataforma web que auxilie no gerenciamento financeiro de maneira simples, oferecendo tanto uma interface para o controle de gastos quanto ferramentas para simulação de investimentos. Além disso, o projeto busca oferecer um espaço de aprendizado contínuo sobre finanças pessoais, com recomendações de livros, cursos e notícias.

## 📝 Passo a Passo para Execução

Para rodar a aplicação localmente, siga as instruções abaixo:

### 1. Instalar o Node.js
Certifique-se de que o **Node.js** está instalado no seu computador. Você pode baixar a versão mais recente no [site oficial do Node.js](https://nodejs.org/).

### 2. Clonar o repositório

Clone este repositório para o seu computador:

```bash
 git clone https://github.com/eduardavieira-dev/Moneo.git
```

### 3. Instalar as dependências

Após clonar o repositório, navegue até a pasta do projeto e execute o seguinte comando no terminal para instalar as dependências:

```bash
 cd codigo
 npm install
```

Esse comando vai instalar todas as dependências do projeto, incluindo o **JSON-server** para manipulação de dados e o **Node.js** para o back-end.

### 4. Rodar o servidor

Com as dependências instaladas, basta rodar o servidor para iniciar a aplicação. Execute o seguinte comando no terminal:

```bash
 npm start
```

O servidor será iniciado, e você poderá acessar a aplicação no seu navegador através de:

```
http://localhost:3000
```
